1. Welcome to Vocalis, a local speech delivery analytics project for Track C. The application compares a participant recording with a reference speaking the same text. It preserves the actual acoustic measurements behind each flagged region. The complete workflow includes microphone recording, editable local transcription, word alignment, a versioned scoring rubric, synchronized playback, plots and downloadable reports. Processing uses pretrained speech models on the laptop CPU. No paid transcription API or dedicated graphics card is required. This walkthrough shows genuine exported results from the completed local system. It is generated from saved evidence rather than being a live browser recording.

2. The custom dataset contains ten reference excerpts and seventy controlled variants. Three source speeches by Reagan and Eisenhower provide matching transcripts and attributed provenance. Every excerpt has a spectrum of edits: mild and severe rushing, slowing, an inserted awkward pause, reduced energy, flattened pitch, and a recording with no injected delivery flaw. Ground truth comes from the exact transformation intervals and time mappings. Each audio file has a checksum. All excerpts of one original speech remain in the same dataset split. The held-out test speaker is Eisenhower. These controlled labels are precise edit records, not human judgments that a delivery is universally ideal.

3. The local inference pipeline begins with Faster Whisper in eight-bit CPU mode and voice activity detection. Its output is an editable draft. After confirming the spoken words, a pretrained wav two vec model produces actual word timestamps with C T C forced alignment. Acoustic extraction measures pitch, energy, articulation rate, pauses, M F C C features and spectral centroid. Median centering compensates for differences in vocal register and recording gain. Matching word boundaries map the reference into the participant's clock. This allows the report to compare corresponding passages even when delivery timing differs, rather than placing unrelated moments on top of one another.

4. This chart shows the actual pitch curves for a reference passage and a participant variant with intentionally reduced pitch variation. Green is the reference and purple is the participant. The shaded interval is the returned flaw region. The detector compares the interquartile range of centered semitone pitch over corresponding voiced frames. The report preserves both measurements and their difference, so the explanation can be checked mathematically. Users can click the flaw or a transcript word to replay that passage. Isolated pitch tracking errors are handled with a robust spread measure. Unavailable pitch is excluded from scoring rather than being mistaken for perfect delivery.

5. Here the participant's energy has been reduced in a known local passage. Both recordings are normalized against their own speech-active median so a simple global recording gain change does not define a delivery flaw. The detector compares normalized decibel values inside aligned spoken-word windows. It retains quiet speech instead of discarding the very region being measured. Local pacing uses matching phrases, and pause detection compares corresponding adjacent words, including repeated words. The selected rubric converts measured deviations and their duration into documented deductions. Written recommendations, spoken feedback, and PDF, JSON and CSV downloads all use the same stored report.

6. Verification separates software correctness from speech accuracy. All seventy controlled variants completed real inference without a failed recording. On the speaker-held-out testing split, precision was about seventy-three percent and recall about eighty-nine percent, with an F one score of zero point eight. Mean matched boundary error was approximately zero point two nine seconds. The complete regression suite and production build also pass.

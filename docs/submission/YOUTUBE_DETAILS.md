## Description to paste

Vocalis is Ryucoders' Track C submission for Multimodal AI Hackathon 2026. It compares same-text reference and participant recordings and grounds delivery feedback in acoustic measurements and precise replayable intervals.

This video contains actual dashboard footage, real upload/transcription/inference jobs, dataset annotation inspection, monotone/rushing/pause stress tests, clarity evidence, word/flaw seeking and PDF export. The browser actions are automated, with synthesized offline English narration; API outputs are real.

Code and documentation: https://github.com/Ryukon07/vocalis-speech-analytics

Custom dataset: https://github.com/Ryukon07/vocalis-speech-analytics/tree/main/dataset/contrastive

Temporary live preview: https://jackson-nutten-high-taken.trycloudflare.com

The preview is served from a laptop through HTTPS and requires it to remain online. The repository includes reproducible local setup instructions and the six-page technical document.

Results describe a small controlled corpus, not all accents or natural delivery styles. Dataset attribution and recording-source reuse notes are in dataset/LICENSE_NOTES.md. Uploaded private microphone recordings are excluded from publication.

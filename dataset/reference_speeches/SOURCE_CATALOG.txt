DOWNLOAD WHEN ONLINE
Run: python tools/download_references.py
Run from this directory, or pass the script's absolute path from any directory.
The script downloads originals and available page transcripts. If FFmpeg is
installed, it also writes mono, 16 kHz PCM WAV copies. Otherwise originals remain
available and can be converted later with --convert-only.
The downloader has only been checked offline; live archive retrieval remains
unverified. If a page changes or its media is loaded dynamically, it reports the
failed item and its source URL for manual download.

BEFORE EVALUATION
Use 20-40 second passages with complete sentences and no overlapping applause,
music, translation, introductions or other speakers. Confirm the transcript by
listening. Do not remove rhetorical pauses. Conversion to WAV does not remove
historical noise or improve recording fidelity. Keep originals for provenance.
These are reference candidates, not the paired contrastive dataset by themselves.

ATTRIBUTION
sources.json retains speaker, date, archive attribution and source URLs. No
file-specific recording license has been certified. Check the recording's reuse
terms before including it in a publicly redistributed dataset.
